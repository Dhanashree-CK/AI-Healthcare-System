# AI-Enabled Healthcare Assistance System

I built this as a web app to make a few everyday healthcare tasks simpler. You can book a doctor's appointment, ask an AI chatbot your questions, and paste in a prescription to get a short summary in plain language.

## Why I made this

Booking an appointment often takes more steps than it should, and prescriptions can be hard to read if you're not used to the terms. I wanted to put both in one place and add a chatbot that can answer basic questions without making you search around.

## What it does

- Lets you book appointments with doctors
- Has an AI chatbot you can ask questions
- Summarizes prescriptions so they're easier to understand
- Works on both phones and computers

## Built with

- Python for the backend
- MySQL for the database
- HTML, CSS and JavaScript for the frontend
